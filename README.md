# Grayson Burger

A simple one‑page website built for practice.  
The project focuses on responsive design for mobile devices and includes a JavaScript‑powered burger menu.

## Features
- Responsive layout for desktop, tablet, and mobile.
- Burger menu implemented with JavaScript.
- Smooth navigation experience.
- Modern HTML5 and CSS3 structure.

## Technologies
- **HTML5** — semantic page structure
- **CSS3** — styling and responsive design
- **JavaScript (ES6)** — interactive burger menu
